# 数据集说明：拆分后的 HTTP 流量样本

## 📁 文件说明
本目录存放 **CIC-IDS2017 数据集** 中 HTTP 流量的测试样本，已按单文件不超过 1MB 的大小拆分为 5 个文件，用于项目中的 AC 自动机入侵检测测试。

| 文件名 | 说明 |
| :--- | :--- |
| `http_1.txt` | HTTP 流量样本第 1 部分 |
| `http_2.txt` | HTTP 流量样本第 2 部分 |
| `http_3.txt` | HTTP 流量样本第 3 部分 |
| `http_4.txt` | HTTP 流量样本第 4 部分 |
| `http_5.txt` | HTTP 流量样本第 5 部分 |

> 注：因按文本内容拆分，各文件大小略有差异，但内容连续、无丢失，不影响检测结果。

## ⚠️ 为什么要拆分？
原始单文件大小超过 GitHub 在线预览限制，拆分后：
- 每个文件均小于 1MB，可直接在 GitHub 上在线预览内容
- **不影响检测结果**：AC 自动机程序会按顺序读取所有 `http_*.txt` 文件，匹配效果与单个大文件完全一致
- 便于用户按需下载、查看和调试

## 📌 数据集来源
本数据来自公开数据集 **CIC-IDS2017**，用于网络入侵检测系统的测试与评估。
官网：[https://www.unb.ca/cic/datasets/ids-2017.html](https://www.unb.ca/cic/datasets/ids-2017.html)

## 🚀 使用方式
运行项目时，程序会自动读取本目录下的所有 `http_*.txt` 文件，进行入侵特征匹配检测，无需手动合并文件。
